# Buildathon Keepsake Studio

A small static site for creating a personal, unofficial Buildathon keepsake. It does not overlay or alter an event-issued certificate; the exported PNG is a separate commemorative design with an explicit unofficial label. Names stay in the browser.

## Run locally

Open `index.html` in a modern browser, or serve the folder with any static file server.

## Deploy

Import this folder/repository into Vercel as a static site (no build command; output directory `.`), or push it to GitHub Pages. The app has no backend or secret environment variables.
