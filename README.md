# Keepsake

A small Next.js app for making a personal keepsake card. Add a name and optionally preview a photo; the photo stays on-device and is never composited into or modified by the exported card. The original file can be downloaded unchanged.

## Run locally

```sh
npm install
npm run dev
```

## Deploy

Import this repository into Vercel. Next.js is detected automatically; no backend, storage, or environment variables are required.
